# TACHKILA V2

## 1. Travail réalisé

Le projet TACHKILA V2 est une application web permettant de gérer l'effectif d'une équipe de football et ses matchs.

### Gestion de l'effectif
- Affichage des joueurs sous forme de cartes.
- Ajout, modification et suppression des joueurs avec validation des données.
- Désignation du capitaine.
- Recherche de joueurs par nom.
- Filtrage par poste.

### Gestion des matchs (en cours de développement)
- Affichage des matchs sous forme de cartes.
- Ajout, modification et suppression des matchs avec validation.
- Navigation entre les onglets.
- Recherche de matchs.
- Saisie des scores et affichage du résultat avec des couleurs différentes.

## 2. Technologies utilisées

- **HTML5** : pour structurer les pages web.
- **Tailwind CSS** : pour le design et la mise en forme de l'interface.
- **JavaScript (ES6+)** : pour gérer les interactions, les événements, la manipulation du DOM, la validation des formulaires, les modules JavaScript et le stockage des données avec localStorage.
- **Git et GitHub** : pour gérer les versions du projet et suivre les modifications.
- **Vercel et GitHub Pages** : pour le déploiement et la publication du site.

## 3. Ce que j'ai appris
